01 / Get started

Bring your game. We supply the app.

01 — SIDELOAD

Install the IPA

Download the IPA and import it into your configured sideloading tool. It must be signed for your Apple account and device. A download link alone cannot install it.

SideStore setup guide ↗

02 — ADD DATA

Copy your MW2 files

Launch once, then copy your own Windows MW2 (2009) installation into the app’s Documents/Games folder using file sharing. Keep the original folder structure, including main and zone.

In Finder, select your connected iPhone → Files → IW4L. The app’s Documents folder is the file-sharing root.

03 — PLAY

Start with Rust

Open Create Lobby, choose Rust in Game Setup and start a match. Connect a compatible controller or use the onscreen controls. Start with zero or one bot.

For a second phone: use the same app version and Wi-Fi, allow Local Network access, then select Find Lobbies.

Memory capability matters. Large maps need the Increased Memory Limit entitlement. Your signing tool and provisioning profile must preserve and permit it. Xcode-signed builds were tested; this public IPA has not yet been verified through every sideloading tool. If your tool cannot retain the capability, use the included source with Xcode.

Before you download

  • Larger maps still have low frame rates, loading stutter and possible crashes. All maps have not been validated.
  • Test hardware: iPhone 13 Pro Max and iPhone 15 Pro. Older devices and older iOS versions are unverified; the build targets iOS 16 or later.
  • Controller movement, aiming and firing are confirmed. Touch controls cover gameplay and menus; full touch interaction coverage is ongoing.
  • Wi-Fi peers can see each other and move. Further testing of damage, match modes and long sessions is needed.
  • Campaign and official PC, Xbox, PlayStation or IW4x server compatibility are not included.
03 / Field notes

A few useful answers.

Does the download contain the full game?

No. It contains the IW4L runtime, not original maps, textures, sounds or other MW2 game assets. Supply your own installed Windows MW2 (2009) data. Console data and the campaign remaster are not the tested source.

Can two iPhones play without a Mac?

Yes: one iPhone hosts the lobby and relay, while the other discovers it over the same Wi-Fi. Both need their own game data and matching app versions. Keep the host app open; networks that isolate clients may prevent discovery.

Which controls are supported?

A GameSir G8 Plus paired as a DualShock controller was tested. The left stick moves, right stick aims, L2 aims down sights, R2 fires, Cross jumps and Options opens the menu. Without a controller, touch buttons and drag areas appear automatically.

Why does an app stop launching after sideloading?

Check the signing status and refresh requirements in your sideloading tool. Signing expiry is separate from an in-game crash. Follow your tool’s documentation; do not remove the app before backing up its Documents folder if you want to preserve data.

Where are the source code and checksums?

The release page includes the modified source archive, IPA and SHA-256 checksums. Original runtime development is by vladtrc / IW4L. This is a community iOS adaptation.
